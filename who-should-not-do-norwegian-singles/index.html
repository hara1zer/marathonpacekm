When Norwegian Singles may not fit your training

Norwegian Singles is a label used here for controlled threshold sessions on separate days. The label does not make a workout appropriate for every runner. This guide is a planning checklist, not a medical screening test.

Start with the problem you are trying to solve

If you are still establishing regular easy running, adding several threshold sessions introduces a second challenge before the first is settled. Keep a repeatable schedule first. There is no universal mileage threshold at which this method suddenly becomes suitable.

When to postpone it

  • Current pain or a disrupted return: a pace calculator cannot establish readiness to train through an injury. An individual assessment takes priority over adding intensity.
  • You cannot keep the repetitions controlled: repeatedly turning the last repetition into a race defeats the session’s intended pacing. Reduce the work or use easy running rather than forcing a target from a calculator.
  • It displaces recovery: if the next easy run or long run is repeatedly compromised, the current combination does not fit your week.
  • You already have a demanding marathon week: count marathon-pace blocks, fast finishes and races as work too. Do not simply add threshold days on top.

A practical decision for a five-run week

Suppose your current week includes three easy runs, one workout and one long run. Replacing an easy run with another threshold session changes the balance of the week. First decide which existing work it replaces and how you will judge recovery. Keeping one controlled workout is a valid choice; following a named method is not the goal.

In my Sydney review, the useful lesson was that impressive isolated sessions did not establish sustainable marathon pace. That experience is not a trial of Norwegian Singles and does not prove one method better than another.

If you decide to explore it

Use the workout guide to understand the format and the pace calculator as an initial estimate. A calculated pace is not a lactate measurement. Review how the session felt and how you recovered before changing the next week.
