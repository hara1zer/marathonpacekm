How to read these calendars

Start with the number of days you already run consistently. These are illustrative calendars for someone accustomed to quality work, not a beginner progression or a promise of improvement. “Quality” means one already tolerated controlled session. “Long easy” means a longer easy run; a fast finish changes its workload and should be counted separately.

The overview explains why single describes the quality day, not a mandatory once-a-week rule.

Check the existing week first

List every demanding session you already do: club intervals, races, tempo runs, long-run blocks and steep hills. Adding one threshold session without removing anything is an increase in workload, even if the new session feels controlled. Use the suitability checklist when recovery or the basic routine is unstable.

Wednesday is the added run. Six days can mean more load even when the quality dose is unchanged. Do not assume the most frequent version is the best starting choice.

Change one variable and inspect the next week

For an already tolerated 4 × 5-minute session, changing to 5 × 5 minutes increases work from 20 to 25 minutes: 25% more. Keeping four repetitions but changing each to six minutes adds 20%. Increasing repetitions and pace together prevents you from knowing which change affected recovery. These are dose comparisons, not a required progression sequence.

Use the rest of the week as feedback

Record whether easy runs became unusually demanding, the long run deteriorated or fatigue persisted. Replace or reduce the quality session when it is displacing the training you need most. Pain, illness or unexplained symptoms need a different response from changing a pace target.

A fast long run changes this calendar

Adding marathon-pace blocks to Sunday creates a second demanding day. Consider replacing Tuesday’s quality with easy running instead of preserving both by habit. The marathon page works through that tradeoff.

Count demands, not labels

  • Calling a fast finish “easy” because it happens in a long run.
  • Adding a second threshold day just because more running days are available.
  • Skipping warm-up, recoveries and cooldown when comparing time costs.

Calendar FAQ

Do six running days require more threshold sessions?

No. These examples keep one quality session and add easy running. More days do not determine an individual’s suitable quality dose.

Which version should I choose?

Compare with the routine you already tolerate. The calendars illustrate scheduling choices rather than assign a level or guarantee readiness.
